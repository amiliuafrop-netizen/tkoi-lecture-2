# ТКОІ · Тема 2.1 · Частина 1

**Створення та обробка графічного контенту. Растрова і векторна графіка, обробка фотографій.**

Інтерактивний навчальний вебсайт українською мовою для студентів.

## Перегляд

Якщо для репозиторію увімкнено GitHub Pages (джерело: гілка `main`, папка `/ (root)`), адреса лекції:

https://amiliuafrop-netizen.github.io/tkoi-lecture-2/tema-2-1-ch1/

Для локального перегляду відкрийте `index.html` у браузері. Файли `style.css` та `app.js` мають залишатися поряд із ним.

## Зміст

- Навіщо потрібна цифрова графіка.
- Растрові пікселі й векторні контури з інтерактивним порівнянням.
- Роздільність, мегапікселі, PPI та DPI, калькулятор розміру відбитка.
- RGB, CMYK, HEX та інтерактивний вибір кольору.
- JPG, PNG, WebP, AVIF, TIFF, RAW, SVG, PSD / XCF.
- Редактори та процес обробки фотографій.
- Демонстрація зміни яскравості, контрасту й насиченості.
- Композиція, етика, авторство, кейси й тест із 10 запитань.

Усі тестові відповіді обробляються **локально в браузері**. Відповіді не збираються і не надсилаються на сервер.

## Викладання

- **Аа / Для проєктора** збільшує шрифти та приховує бічне меню.
- **PDF / друк** запускає друк браузера. Для PDF оберіть «Зберегти як PDF».
- Сторінка адаптована до комп'ютера, планшета й телефона.
- Для головного фотографічного прикладу використовується зовнішній файл Unsplash. Без доступу до нього градієнтний фон і весь текст/тест залишаються доступними.

## GitHub Pages

Якщо сайт не відкривається, перейдіть до **Settings → Pages**, оберіть **Deploy from a branch → main → / (root)** та збережіть. Дочірня папка `tema-2-1-ch1` тоді буде доступна за адресою вище.
