# Практична робота №4 — Canva

**ТКОІ · Дослідження інструментарію графічних редакторів та їх використання для базової візуальної комунікації.**

Навчальна платформа українською мовою. Студенти працюють у [Canva](https://www.canva.com/), а тут читають інструкції, фіксують результати, додають скриншоти й формують звіт.

## Посилання

Якщо в репозиторії налаштовано GitHub Pages (main, /root), сторінка доступна тут:

https://amiliuafrop-netizen.github.io/tkoi-lecture-2/practical-4-canva/

## Завдання

1. **Дослідити Canva:** створити дизайн 1080 × 1350 px; знайти текст, елементи, завантаження, роботу з кольором. Додати скриншот.
2. **Обробити фотографію:** кадрування, яскравість, контраст, насиченість. Додати скриншоти «до» й «після».
3. **Створити афішу** «Цифрова грамотність: навички майбутнього»: заголовок, три тематичні блоки, фото, щонайменше дві фігури, узгоджена палітра. Додати скриншот процесу.
4. **Експортувати в PNG** і перевірити якість. Додати фінальну афішу та скриншот параметрів експорту.

## Звіт

В кінці сторінки студент заповнює ПІБ, групу, дату й висновок. Автоматично збирається документ зі структурою:

- **ПРАКТИЧНА РОБОТА №4**
- **Тема**
- **Мета**
- **Студент / група / дата**
- **Хід виконання роботи**, етапи 1–4, опис виконаних дій, скриншоти 1–6
- **Висновок**

Натиснути **«Переглянути готовий звіт»**, а після заповнення всіх полів — **«Зберегти як PDF»**; у діалозі друку браузера обрати **«Зберегти як PDF»**. Сайт не створює PDF на сервері та не надсилає дані викладачу.

Здати в Google Classroom:
- PDF-звіт;
- PNG-файл готової афіші.

Текстові поля й галочки автоматично зберігаються в локальному сховищі браузера, якщо браузер це підтримує. Скриншоти існують лише у відкритій вкладці. Для збереження **усіх** даних між заняттями натиснути **«Зберегти чернетку»**; відновити можна з файлу JSON. Чернетку зберігати конфіденційно, оскільки вона містить ПІБ, пояснення та фото.
